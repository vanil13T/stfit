## Какой файл выбрать

В разделе Releases лежит несколько файлов. Если не уверены — берите
`app-universal-release.apk`: он ставится на любой телефон.

| Файл | Кому | Размер |
|---|---|---|
| `app-arm64-v8a-release.apk` | Почти все телефоны с 2017 года | ~30 МБ |
| `app-armeabi-v7a-release.apk` | Старые телефоны | ~20 МБ |
| `app-universal-release.apk` | Если не знаете, какой из двух | ~97 МБ |

## Как установить APK

1. Скачайте файл на телефон.
2. Откройте его — Android спросит разрешение устанавливать приложения
   из этого источника. Разрешите.
3. Если появится предупреждение Play Protect — это обычное сообщение для
   приложений не из магазина. Нажмите «Всё равно установить».

Обновления при установке из APK не приходят автоматически — возвращайтесь
на эту страницу или ставьте из магазина.

## Что внутри

- Шаги считаются сами, даже когда приложение закрыто
- Прогулки и велосипед по GPS: дистанция, темп, трек
- Дневник зала: 192 упражнения, подходы с весом и оценкой тяжести,
  рекорды, шаблоны, таймер отдыха
- Дневник питания с базой на 7800 продуктов
- Медитации, дневник самочувствия, контроль веса
- 70 наград, два стиля оформления
- Работает без интернета
